# 🚀 Пакет автонастройки Passwall2 для OpenWrt

🌐 **Языки:** [English](README.md) | [فارسی](README_fa.md) | [Русский](README_ru.md) | [简体中文](README_zh.md)

Автоматизированный, надежный и многофункциональный скрипт для установки и настройки **Passwall2** на роутерах OpenWrt.

Разработан с учетом различий в пакетных менеджерах между версиями OpenWrt, автоматически разрешает зависимости ядра и DNS, поддерживает загрузку релизов из нескольких источников (включая иранское локальное зеркало) и применяет опциональные региональные оптимизации сети и системы.

---

## ✨ Основные возможности

| Функция | Описание |
| :--- | :--- |
| ⚡ **Независимость от пакетного менеджера** | Полная поддержка как современных версий OpenWrt (`apk` в OpenWrt 24.10 / 25+), так и классических (`opkg`), прозрачная работа с пакетами `.apk` и `.ipk`. |
| 🌐 **Трехисточниковый движок** | Установка из официальных фидов SourceForge (по умолчанию), напрямую из **GitHub Releases** (`-g`) или через **иранское локальное зеркало GitHub** (`-gm`) на `scorpian.ir`. |
| 📦 **Настраиваемые профили** | Выбор между **Standard** (оба ядра: Xray и Sing-Box), **Full Feature** (`-f`), **Minimal Xray** (`-x`), **Minimal Sing-Box** (`-s`) или **Только LuCI UI** (`-l`) в соответствии с ресурсами вашего роутера. |
| 🛡️ **Надежный механизм fallback для ядер** | Автоматически гарантирует установку прокси-ядер (`xray-core`, `sing-box`) даже после того, как апстрим удалил их из архивов релизов. В режиме иранского зеркала (`-gm`) ядра загружаются напрямую с локальных зеркал (`scorpian.ir/repos/XTLS/Xray-core` и `scorpian.ir/repos/sagernet/sing-box`) на максимальной скорости без блокировок, с автоматическим откатом к официальным релизам GitHub. |
| 🛠️ **Бесшовный переход без простоя сети** | Безопасный апгрейд `dnsmasq` до `dnsmasq-full` и установка модулей ядра (`kmod-nft-tproxy`, `kmod-nft-socket`) с сохранением активного интернет-соединения через резервные резолверы. |
| 🇮🇷 **Региональные настройки для Ирана** | Специальный флаг (`-i`) инициализирует локальный DNS (`5.200.200.200`) в самом начале работы скрипта для обхода блокировок DNS, устанавливает часовой пояс `Asia/Tehran`, исправляет DNS Rebinding для порталов операторов (*Irancell, MCI, TCI*) и применяет патч баннера статуса Passwall. |
| 🔑 **Аварийный сброс пароля** | Переназначает аппаратную кнопку сброса (`-rb`): 5-секундное удержание сбрасывает пароль root по SSH без потери настроек роутера. |
| 📶 **Быстрая настройка паролей по умолчанию** | Быстрая установка единого пароля `123456789` для Wi-Fi (2.4GHz и 5GHz) и root SSH (`-rw`). |

## ⚡ Быстрый старт

Запустите скрипт автоматической установки через SSH на вашем роутере OpenWrt:

```bash
rm -f /tmp/set.sh && wget -O /tmp/set.sh https://raw.githubusercontent.com/sadraimam/auto_passwall2/refs/heads/main/set.sh && chmod +x /tmp/set.sh && sh /tmp/set.sh
```

## 🎛️ Параметры командной строки и флаги

Настройте установку, добавив нужные флаги при запуске скрипта:

| Флаг | Полная опция | Описание |
| :--- | :--- | :--- |
| `-g [VER]` | `--github [VER]` | Установка напрямую из GitHub Releases вместо фидов SourceForge. Опционально можно указать тег релиза (например, `26.8.17-1`). |
| `-gm [VER]` | `--github-mirror [VER]` | Установка через **иранское зеркало GitHub** (`scorpian.ir`). Позволяет обойти rate-limiting GitHub, загрязнение DNS и троттлинг провайдеров. Псевдоним: `-m`. |
| `-c` | `--clean` | Чистая установка. Удаляет ранее установленные пакеты Passwall2 и исполняемые файлы перед установкой для исключения конфликтов. |
| `-x` | `--xray` | Минимальная установка только с ядром **xray-core** (пропускает sing-box и лишние утилиты для экономии флеш-памяти). |
| `-s` | `--singbox` | Минимальная установка только с ядром **sing-box** (пропускает xray-core и лишние утилиты для экономии флеш-памяти). |
| `-lb` | `--loadbalancing` | Установка и проверка пакетов балансировки нагрузки (`haproxy`, `microsocks`). Работает с `-s`, `-x` или профилем по умолчанию; автоматически пропускается при использовании `-f` (уже входит в полную установку). |
| `-f` | `--full` | Полная установка. Включает все ядра прокси и инструменты: `chinadns-ng`, `hysteria`, `haproxy`, `microsocks`, `naiveproxy`, `xray-core`, `sing-box`, `geoview`, `v2ray-geoip`, `v2ray-geosite`, `tcping`. |
| `-l` | `--only-luci` | Установка только веб-интерфейса LuCI (`luci-app-passwall2`). Без скачивания бинарных пакетов (удобно, если ядра уже встроены в прошивку). |
| `-i` | `--iran` | Применение региональных настроек для Ирана: инициализация локального DNS `5.200.200.200` на старте скрипта, часовой пояс `Asia/Tehran`, фикс DNS rebinding (`my.irancell.ir`, `my.mci.ir`, `login.tci.ir`) и патч баннера Passwall. |
| `-rw` | `--root-wifi` | Установка пароля root SSH и Wi-Fi 2.4GHz/5GHz в значение `123456789`. |
| `-rb` | `--reset-button` | Перенастройка кнопки сброса: 1 секунда — перезагрузка роутера; 5 секунд — сброс пароля root (`passwd -d root`). |
| `-nf` | `--no-feed` | Не добавлять фид passwall build; устанавливать ядра из имеющихся репозиториев. |
| `-ns` | `--no-restart` | Не перезапускать сервисы Passwall2 после завершения установки. |
| `-h` | `--help` | Показать справку по использованию скрипта и выйти. |

## 💡 Примеры установки

### 1. Рекомендуемая конфигурация для Ирана (высокая скорость и стабильность)
Использует иранское зеркало GitHub, чистую установку, настройку паролей root/Wi-Fi и региональные исправления:
```bash
sh /tmp/set.sh -gm -c -rw -i
```

### 2. Чистая установка из официальных релизов GitHub (оба ядра)
Загружает свежие бинарные релизы напрямую с GitHub, гарантируя установку как Xray, так и Sing-box:
```bash
sh /tmp/set.sh -g -c
```

### 3. Минимальная установка только Xray (максимальная экономия места)
Устанавливает только `xray-core` и необходимые гео-базы, оставляя максимум свободного места в разделе overlay:
```bash
sh /tmp/set.sh -x -c
```

### 4. Минимальная установка Sing-Box с балансировкой нагрузки
Устанавливает легкое ядро `sing-box` вместе с `haproxy` и `microsocks` для балансировки нагрузки:
```bash
sh /tmp/set.sh -gm -s -lb -i
```

### 5. Установка конкретной версии релиза
Установка определенной версии релиза (например, `26.8.17-1`) через иранское зеркало:
```bash
sh /tmp/set.sh -gm 26.8.17-1 -c
```

### 6. Полный стек со всеми протоколами
Устанавливает все поддерживаемые ядра прокси-протоколов (Hysteria, NaiveProxy, HAProxy, ChinaDNS-NG и др.):
```bash
sh /tmp/set.sh -f -c
```

## 📋 Системные требования

- **Поддерживаемая ОС:** OpenWrt (поддерживаются как официальные релизные сборки, так и snapshot-сборки).
- **Архитектура процессора:** `x86_64`, `aarch64_cortex-a53`, `aarch64_cortex-a72`, `aarch64_generic`, `arm_cortex-a7`, `arm_cortex-a15`, `mipsel_24kc`, `mips_24kc` и др.
- **Минимальные аппаратные требования:**
  - **Flash-память:** 128 МБ (60+ МБ свободного места в overlay)
  - **RAM:** 256 МБ

> [!NOTE]
> **Xiaomi AX3000T и устройства с ограниченным объемом памяти:**
> Заводская разметка на Xiaomi AX3000T оставляет под overlay около 60 МБ. Данный скрипт оптимизирован для работы в этих условиях. Для наилучшего результата рекомендуется использовать минимальный режим sing-box (`-s`) или установить кастомную разметку U-Boot, чтобы получить ~85 МБ раздела overlay.

## 🛠️ Безопасность и восстановление

- **Резервное копирование:** Существующие конфигурации Passwall в `/etc/config/passwall2*` автоматически копируются с добавлением суффикса даты (`.bak`) перед внесением изменений.
- **Аварийный сброс пароля (`-rb`):** Если вы потеряли доступ к SSH, 5-секундное удержание физической кнопки сброса очистит пароль root без сброса сетевых настроек и установленных пакетов.
- **Контроль свободного места:** Скрипт проверяет свободную память в `/tmp` перед загрузкой пакетов и выводит рекомендации по очистке диска при нехватке места.
